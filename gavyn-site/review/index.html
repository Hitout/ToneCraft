ToneCraft: background metronome playback

Android demonstration for the FOREGROUND_SERVICE_MEDIA_PLAYBACK declaration.

  1. The user opens ToneCraft and starts the metronome.
  2. The user returns to the home screen while the audible beats continue.
  3. The user opens the notification panel and stops playback using the media notification.

Recorded on an Android device. Sound is included; enable audio in the player to hear the beats.
