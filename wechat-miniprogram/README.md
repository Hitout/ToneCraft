# ToneCraft 微信小程序

ToneCraft 的微信小程序版本，包含节拍器与调音器，采用深色暖色视觉和交互模型。

## 运行

1. 在当前目录执行 `npm install`。
2. 用微信开发者工具导入当前 `wechat-miniprogram` 目录。
3. 使用你有权限管理的 AppID，导入后勾选“使用 npm 模块”。
4. 运行 `npm run typecheck` 和 `npm test` 做本地检查。

公开仓库不提交 `miniprogram/assets/icons/` 原始图标目录，而是提供 `miniprogram/assets/icons2/` 作为公开替代素材。首次启动项目且本地没有授权的 `icons` 目录时，请先将 `icons2` 重命名为 `icons`；如果你已有私有或自行制作的 `icons` 目录，请保留现有目录，不要覆盖原始素材。

## 音频实现

节拍器使用 `wx.createWebAudioContext()`。启动时根据音频上下文的实际采样率，把机械、电子、鼓组、牛铃和快板五种音色的 PCM 渲染到 `AudioBuffer`；播放时以 `audioContext.currentTime` 为时钟，用 `BufferSourceNode.start(when)` 提前调度未来节拍。

调音器通过 `RecorderManager` 采集单声道 PCM，在端内使用 YIN 自相关算法识别音高；音频仅在内存中用于实时分析，不保存也不上传。

JavaScript 定时器只负责补充节拍高亮和维护调度窗口，不直接决定发声时刻。小程序只保证前台运行，音频不会上传；调音器的录音与分析仅在前台实时执行。

## 首期范围

- 已实现：BPM 20–300 调节、拖动旋钮、Tap Tempo、拍号、四种细分及休止细分、五种音色、节拍强弱编辑、速度训练、前台倒计时、节拍视觉高亮；吉他、尤克里里、贝斯、小提琴与半音阶调音，自动/手动选弦、音分趋势与调准确认。
- 未实现：全屏、闪光灯、震动、国际化、后台节拍器。

## 真机验收重点

需要在 Android 和 iOS 真机分别检查：首次点击播放到首拍的延迟、连续运行一段时间后的长期漂移、切后台再回前台后的音频上下文恢复，以及不同系统音频输出设备下的听感和音量。小程序只保证前台运行，底层音频能力受微信运行时和设备支持影响。

## 发布前检查

正式发布前，请根据实际录音、本地存储和其他平台接口的使用方式，补充并审核微信小程序的用户隐私保护指引和公开隐私说明。
