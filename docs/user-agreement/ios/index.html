二、权限与设备功能

调音器需要麦克风权限，实时音频仅用于设备内音高分析，不保存为录音文件或上传。你可以在系统设置中拒绝或撤回权限；未获麦克风权限时调音不可用，其他无需该权限的功能仍可使用。

节拍闪光仅在启用时请求相机权限以控制闪光灯，不拍照或录像；震动和闪光取决于设备能力。节拍器可在系统允许时后台或锁屏播放，你可以在应用或系统媒体控制中停止；后台节拍播放不会开启调音器麦克风。
